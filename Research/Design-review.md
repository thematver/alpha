## Remaining limits

- No browser-rendered golden image or numerical pixel-diff score was produced. Inspection uses extracted HTML/SVG coordinates, native renders and source colour/font definitions. This does not establish exact pixel equivalence to a browser rendering.
- MIDI learn, controller follow-focus, drag reordering, engine swap, input-spectrum Alt overlay and per-engine Alt solo are not exposed as working controls.
- A/B edits the existing processor scenes. Shared modes, frequency ranges, motion profiles and global settings are not two fully independent complete plugin states; histories are editor session history.
- Existing algorithms are retained where the codebase implements a smaller set than the design board. HEAT exposes the five reference algorithms; original soft clip remains accessible through its algorithm menu. DUST sample-file import and a user-preset card catalog are not implemented.
- Preset files use the codebase's versioned processor state format rather than the board's proposed JSON schema.
- FFT size is 4096 with a Hann window, but analysis runs during visible editor updates rather than the board's proposed background analyzer pipeline. There is no claim of the board's exact 1/6-octave smoothing or per-engine RMS breathing.
- Visible idle updates fall to 10 Hz after two seconds without signal or gestures and return to 60 Hz on activity. Hidden editor updates skip analyzer and paint refresh. Reduced motion removes the implemented view/selection transitions.
- Native build formats are AU and Standalone. The board's other plugin formats and iPad-specific gestures are outside this implementation.

These limits should remain explicit; the implementation should not be described as implementing every item on all nine specification boards.
